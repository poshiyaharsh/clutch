# Design rules
- Use only tokens from design/genz-theme.css and docs/DESIGN_SYSTEM.md.
- Mobile first at 375px, 44px touch targets, visible focus, 4.5:1 contrast.
- Buttons say what happens (sentence case). Errors say what went wrong and how to fix it. Empty states invite action.
- Motion only for the leaderboard moment and user-triggered feedback. Respect prefers-reduced-motion.
- No new colors, fonts or radii without updating DESIGN_SYSTEM.md first.
